# Debate and review record

Chronological record of how the design of `recon2` was argued, verified and decided. Files `01–08`
and some of `09–13` are the original artefacts written during the debate; the remaining files are
faithful transcriptions of reports delivered in the same session. All numbers come from the data.

| # | File | Stage |
|---|---|---|

| 02 | `02_exploration_old_engine_code.md` | what the inherited engine did, its bugs, per-segment accuracy |
| 03 | `03_exploration_train_golden_mining.md` | empirical rules mined from TRAIN golden |
| 04 | `04a/b/c_brief_*.md` | domain briefs: accountant, treasury, documents |
| 05 | `05_proposal_v1_architect.md` | first full design |
| 06 | `06a–d_round1_critique_*.md` | round 1: accountant, treasury, documents, red-team |
| 07 | `07_verifier_batch1.md` | disputes settled with data |
| 08 | `08_proposal_v2_architect.md` | revised design answering every blocker |
| 09 | `09ab_…`, `09c_…` | round 2 critiques; the rewrite-vs-port decision |
| 10 | `10_build_reports.md` | six parallel builders |
| 11 | `11a_review_code_round1.md`, `11b_reviews_and_cross_debate.md` | post-build review and cross-critique |
