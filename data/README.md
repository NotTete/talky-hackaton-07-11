# data/

Everything here is generated by `scripts/download_data.py` and is gitignored
(except this file). Delete any directory here and re-run the script; nothing else
depends on its contents.

```
archives/     exactly what the server served, sha256-checked, never edited
manifest.json url / bytes / sha256 / extraction log for every archive
masters/      shared master data (snapshot 2025-12-31)
sample/       one labelled month (from the docs archive)
train/        four labelled years
train-lite/   four labelled years, raw statements + PDFs only from 2024-07
live/         2025-07..12, no golden, leaderboard phase
final/        2026-01..06, released late, ships its own masters_final/
interim/      scratch space (safe to delete)
processed/    scratch space (safe to delete)
```

The spec and the organisers' starter are not kept here: the script copies them to
`../docs/` (they are small and versioned, and they belong next to the code).

Keep the archives: they are the provenance of every score you report, and
`--verify` can prove that what you are training on is what the organisers published.
`--no-keep-archives` deletes them after extraction if disk is tight.
